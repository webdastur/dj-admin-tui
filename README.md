# Django Admin TUI

A terminal UI for the Django admin — browse, search, edit, and run admin
actions from the terminal.

> Working title; PyPI distribution name TBD. The Python import name is
> `admin_tui` and is stable regardless of the final distribution name.

This README is a placeholder. The full operator-facing quickstart and trust
model are tracked in T086 (`/speckit-implement` Phase 7). See
[`specs/001-admin-tui-mvp/quickstart.md`](specs/001-admin-tui-mvp/quickstart.md)
for the current operator walkthrough and
[`.specify/memory/constitution.md`](.specify/memory/constitution.md) for the
project's binding principles.
